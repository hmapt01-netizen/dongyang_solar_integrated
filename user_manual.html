1. 시스템 개요 및 관제 대상 사업장

2. 시스템 로그인 및 세션 관리

STEP 1 초기 시스템 접속

웹 브라우저로 접속 시 딥 블루 톤의 보안 로그인 팝업 모달이 화면 중앙에 나타납니다.

STEP 2 관리자 계정 인증

  • 로그인 권한: 🛡️ 통합 관제 관리자 (Admin) 전용 권한으로 고정 배치되어 있습니다.
  • 기본 계정 정보: 아이디 admin / 비밀번호 1234 가 자동 입력되어 있습니다.
  • 로그인 실행: 하단의 그린 그라데이션 로그인 버튼을 클릭하면 세션이 생성되며 관제 대시보드로 이동합니다.

STEP 3 회원가입 탭

신규 담당자의 경우 상단 회원가입 탭을 클릭하여 성명, 이메일, 비밀번호를 입력 후 신청하면 관리자 승인 절차를 거치게 됩니다.

STEP 4 로그아웃 세션 종료

상단 우측의 로그아웃 버튼을 클릭하면 활성 세션이 안전하게 제거되고 즉시 로그인 팝업 창으로 복귀합니다.

3. 상단 헤더 및 발전소 선택 조작

헤더는 접속 기기 환경에 따라 최적의 레이아웃으로 자동 전환됩니다.

  • PC 데스크톱 환경 (1행 가로 배치):
    좌측에 영농형 태양광 종합관리 제목이 위치하며, 중앙에 🌐 [전체 사업장] 통합 관제 (5개 발전소) 발전소 선택 드롭다운이 로고와 같은 줄에 시원하게 위치합니다.
  • 스마트폰 폰뷰 환경 (2행 높이 96px 구조):
    1행에 로고와 우측 버튼이 배치되고, 2행 전체 폭에 발전소 선택 드롭다운이 확장 표출되어 좁은 화면에서도 텍스트가 잘리지 않습니다.
  • 발전소 변경:
    드롭다운에서 특정 사업장(예: [12139] 온누리3,4)을 선택하면 사업장 상세 화면으로 즉시 전환되며 해당 발전소의 KPI 데이터가 실시간 렌더링됩니다.

4. 좌측 메인 관제 메뉴별 상세 기능

4.1 종합 대시보드 (Dashboard)

5개 전체 사업장의 실시간 영농이행 관제 현황을 한눈에 파악할 수 있는 메인 화면입니다.

  • 상단 KPI 5대 카드: 전체 사업장(5), 정상 이행(3), 관찰 필요(2), 현장점검(0), 시정 검토(0). 카드를 클릭하면 지도가 해당 상태 사업장으로 실시간 필터링됩니다.
  • 강원 관제 지도 & 우선 확인 대상: 지도 마커 및 위험도 순 우선 확인 대상을 표출합니다.
  • 최근 정기점검 리포트 현황: 월간 리포트 결과 목록 및 보기 버튼을 통한 팝업 미리보기를 제공합니다.

4.2 사업장 상세 (Site Detail)

선택된 단일 사업장의 정밀 관제 및 허가 정보 비교를 제공합니다.

  • 2x2 서브탭 바 (1:1 스무스 스크롤):
    개요, 영농활동, 허가·계획, 행정조치 서브탭 클릭 시 해당 섹션 위치로 1:1 매칭되어 원터치 스크롤 이동합니다.
  • 허가 정보 비교: 신고 작물(벼, 콩)과 AI 확인 작물의 일치 여부 및 실경작 면적 비율을 검증합니다.

4.3 이상징후 센터 (Risk Center)

6대 관찰 항목(장기 무활동, 카메라 장애, 휴경 의심, 농기계 미탐지 등) 및 법령 준수사항을 다각도로 검토합니다.

4.4 영상 증빙 검토 (Video Evidence)

현장 AI 카메라(CAM 01~04) 수신 캡처 썸네일과 바운딩 박스를 검토하고 담당자가 인정, 보류, 오탐 판정을 내릴 수 있습니다.

4.5 리포트 센터 (Report Center)

강원특별자치도 제출용 6페이지 정기점검 행정보고서를 미리보고 상단 1-Click PDF 인쇄 / 다운로드 버튼으로 인쇄합니다.

4.6 현장점검 (Inspection)

관찰 필요 또는 시정 조치가 필요한 사업장에 점검관을 지정하고 일정을 수립합니다.

5. 강원 관제 지도 조작 및 뱃지 필터링

📍 지도 상단 뱃지 버튼 클릭 필터링 가이드
  • ● 정상 (3) 뱃지 클릭: 지도에 정상 사업장 3개만 필터링되어 나타나며 전체 구도가 줌인 자동 조율됩니다.
  • ● 관찰 (2) 뱃지 클릭: 관찰 필요 사업장(온누리3,4 및 온누리5,6) 2개만 필터링되어 포커싱 줌인됩니다.
  • 마커 핀 클릭: 마커 핀 클릭 시 해당 사업장의 상세 관제 화면으로 즉시 전환됩니다.
  • 지도 모드 전환: 🗺️ 일반 지도 및 🛰️ 위성 지도 타일 스위칭 버튼을 지원합니다.

6. 스마트폰 폰뷰 모드 및 단축키 활용

PC 환경에서 스마트폰 모바일 화면 모드를 테스트할 수 있는 단축키 기능을 제공합니다.

단축키 기능 설명
F2 스마트폰 모바일 폰뷰 시뮬레이터 토글 (켜기 / 끌기)
Ctrl + M 모바일 폰뷰 시뮬레이터 토글 (한글 키 Ctrl + ㅡ 동일 지원)
📱 실제 모바일 기기 접속 시:
Android, iPhone, iPad 등 실제 모바일 기기로 접속 시에는 별도 단축키 조작 없이 자동으로 폰뷰 모드로 감지 및 전환되어 하단 3x2 그리드 관제 메뉴와 2행 헤더가 표출됩니다.
